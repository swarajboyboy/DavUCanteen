# 🍽️ DavU Canteen – MERN Stack Project

DavU Canteen is a complete food ordering and management system built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.  
The system allows students to browse meals, place orders, make payments, and track order updates.  
Admins can manage the canteen, products, users, and orders through a powerful dashboard.

---

## 🚀 Features

### 🧑‍🍳 **User Features**
- Browse all meals and categories
- Add items to cart
- Login / Signup with JWT authentication
- OTP email verification
- Place orders with address & payment details
- View order confirmation status
- Voice search integrated
- Feedback system

---

### 🛠️ **Admin Features**
- Add / Edit / Delete products
- Upload product images (URL + local file)
- Manage categories (Organic, Ohri Special, Branded, etc.)
- User management (Block / Unblock)
- Order management panel
- Contact messages management
- Offer Management
- Multi-image upload for products (up to 5)

---

## 🧰 Tech Stack

### **Frontend**
- React.js
- React Router
- Axios
- Tailwind / CSS
- JWT Token Management
- SpeechRecognition for voice search

### **Backend**
- Node.js
- Express.js
- MongoDB + Mongoose
- Nodemailer (OTP Verifications)
- JWT Authentication
- REST API Architecture
